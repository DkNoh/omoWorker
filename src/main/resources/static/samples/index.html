정적 샘플 목록 (화면 프로토타입 인덱스)

아래 샘플은 공통 CSS(admin-*.css)로 작성된 정적 HTML 프로토타입이다. 파일을 더블클릭(file://)하거나 서버 기동 후 /samples/파일명으로 열 수 있다.

실제 Thymeleaf 화면으로 전환하는 절차는 각 샘플 파일 상단 주석(6단계)을 참고하고, 자세한 내용은 docs/menual/sample-to-screen_manual.md와 docs/base/screen-convention.md를 본다. prod 프로파일에서는 /samples/**가 404로 차단된다.
