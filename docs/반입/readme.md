# fileList_3 반입 변경 요약

- 작성일: 2026-08-04
- 구성: 프로젝트 파일 105개 + 이 안내 파일 1개
- 기준: `fileList_2.zip`의 파일을 현재 워크스페이스 버전으로 갱신하고 이후 메뉴관리 변경 파일을 추가했다.

## 주요 변경 내역

### 1. 메뉴관리 및 사이드바

- 메뉴 등록·수정 시 부모 메뉴를 기준으로 레벨과 형제 정렬순서를 서버에서 계산한다.
- 자기 자신 또는 자신의 하위 메뉴로 이동하는 순환 계층을 차단한다.
- `G`뿐 아니라 URL이 있는 `M` 화면 메뉴도 하위 메뉴를 가질 수 있도록 부모 타입 제한을 제거했다.
- `M` 메뉴에 자식이 있으면 사이드바에서 화면 이동 링크와 하위 메뉴 펼침 버튼을 분리한다.
- 3LEVEL 이상 메뉴를 재귀적으로 출력하고 현재 화면의 상위 메뉴와 헤더 경로를 함께 펼친다.
- 메뉴 변경이 커밋된 후 기존 로그인 세션의 메뉴 트리와 화면 권한 캐시를 다음 요청에서 갱신한다.
- 메뉴 초기 데이터, 정적 메뉴 기준 및 메뉴관리 관련 DTO·Mapper·Service·화면을 현행화했다.

### 2. 스캐폴드 생성기

- 스캐폴드 Controller·Service·DTO와 메타데이터 분석 및 파일 적용 로직을 현행화했다.
- LIST·CRUD·EXCEL 화면과 Java·Mapper·메뉴 SQL 생성 템플릿을 현재 생성 계약에 맞췄다.
- Oracle 외 PostgreSQL·DB2·MSSQL Mapper XML 생성 결과를 포함한 Golden 기준을 갱신했다.
- 대표 생성 결과와 실제 템플릿이 일치하도록 Golden 테스트 자료를 함께 반입한다.

### 3. 테스트

- 메뉴 캐시 revision, 메뉴 계층 계산·이동 및 사이드바 재귀 렌더링 계약 테스트를 포함한다.
- `fileList_3` 작성 시 메뉴관리 관련 테스트 28개가 통과했다.
